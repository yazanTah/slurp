# Pricing & Features — SLURP Universal Media Downloader

## Community Tier (100% Free)
- **Price**: $0.00 / month
- **Download Limit**: Unlimited
- **Ad Frequency**: Zero ads / Zero trackers
- **Registration**: Not required (instant anonymous access)
- **Supported Platforms**: TikTok, Instagram, YouTube, Facebook, X (Twitter)
- **Features Included**:
  - TikTok multi-photo slideshows to ZIP archive with soundtrack MP3
  - Watermark-free Full HD (1080p) MP4 video downloads
  - Direct CDN streaming with zero transcoding queues
  - High-speed 10ms in-memory store-mode ZIP compression
  - Native mobile browser support for iOS Safari and Android Chrome
  - REST API endpoint access (`/api/resolve`, `/api/stream/video`, `/api/stream/slideshow-zip`)
